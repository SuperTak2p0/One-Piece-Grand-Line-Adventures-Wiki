Getting Started

1

Install Minecraft Forge

Download and install Forge for the Minecraft version required by the mod. (currently 1.20) You can find the correct version listed on the CurseForge page.

2

Download the Mod

Grab the latest release from CurseForge and drop the .jar file into your mods/ folder.

3

Launch Minecraft

Open the Minecraft Launcher, select your Forge profile, and hit Play. The mod will load automatically.

4

Create or Join a World

Start a new world or connect to a server with the mod installed. Your One Piece adventure begins!

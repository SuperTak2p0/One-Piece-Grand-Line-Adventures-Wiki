About this Attack

Basic Punch is the starter melee attack in the mod's combat system. It is a short-range attack available to every player regardless of race or faction. It serves as a test for the Attack Selection GUI and shows how the combat system works at its most fundamental level.

Attack Stats

Property Value
TypeMelee
RangeShort
CooldownShort
RequirementsNone
CategoryBasic

How to Use

Open the Attack Selection GUI (keybind set in your Minecraft controls) and select Basic Punch. Once equipped, activate it in-game with the assigned attack key. More detailed controls and mechanics will be documented as the combat system expands.
